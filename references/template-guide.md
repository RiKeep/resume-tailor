# 模板结构与选择指南

三个模板均为 A4 单页、自包含 HTML（`resume.html` + `assets/photo.jpeg`）。

模板本身是**空骨架**：保留了版式、区块标题与标签（如"姓　　名"），正文容器全部为空，不含任何示例姓名/公司/经历。填充时只需在既有容器里写真实内容，不必先删除示例文字。

选择前先向用户展示各模板的 `preview.jpg`（预览图展示的是**填写后**的效果），不能只报文件名。

## 内容密度参考

`references/example-template-001~003.html` 是三个模板的**已填写样例**，用于判断"一条 bullet 该多长、一段经历写几条、哪些字段会撑高版面"。

- 需要拿捏篇幅时读它，**不要复制其中的示例文字**。
- 三个模板距写满一页的余量都只有约 1–3 行，照抄样例规模是安全的，明显超出就会掉到第 2 页。

## template-001 结构与可编辑点

- `.banner > h1`：顶部大标题（默认"个人简历"）。
- `.profile`：基本信息，两列 grid + 右上角 `.photo`。每个 `.info-item` 含 `.label`（加粗）和 `.value`；可按字段增删，注意左右两列条目数平衡。
- 各 `.section`：`.section-title`（深色块文字 + 灰条）+ 内容。
  - 教育/实习/校内：`.entry-head` 内 `.date` / `.org` / `.role` 三段，下面 `.desc` 或 `.bullet-list`。
  - 一个 `.entry` 代表一段经历，整段复制即可新增。
- 技能/自我评价：`.plain-text` 段落。

## template-002 结构与可编辑点

- `.banner`：`h1` 大标题 + `.slogan` 副标题。
- `.basic`：两列，左列纯文字 `.b-line`，右列 `.b-line` 带 `.ic` 图标；右上 `.photo`。
- 每个 `.section`：箭头 `.section-tag`（`.tri` + `.body` 标题）+ `.section-line`。
- 教育/工作：`.two-col` 两列（`.col-left` 职位专业+时间，`.col-right` 单位+描述），整组复制新增。
- 专业技能：`.skill-list`，每条 `.k` 加粗标签 + 内容。

## template-003 结构与可编辑点

- `.top-bar`：顶部装饰横条，无需改。
- `.header`：`.name-block`（姓名 + 应聘岗位）、`.contact`（三条带图标的 `.c-line`）、`.photo`。
- 每个 `.section`：`.sec-title`（`.icon-circle` 图标 + `h2` + `.line`）+ 内容。
- 经历抬头 `.entry-head`：`.date` / `.org` / `.role` 三段加粗。
- 列表统一用 `.diamond-list`（菱形符号）；文字颜色类 `.c-black` / `.c-dark`。
- 技能证书：`.skill-line`（`.k` + `.v`）。

## 版式保护规则（三个模板通用）

- 只往既有容器里填内容，不改 `<style>` 内任何 CSS 变量、字号、颜色、间距。
- 新增条目时复制同类整块（`.entry` / `.two-col` / `<li>`），保持 class 与结构一致。
- 用不到的条目可整块删除，但不要删掉某个区块的最后一个容器把版式掏空。
- 照片统一替换 `assets/photo.jpeg`（同名覆盖最省事）；用户未提供时保留默认照片，不删块。
- 填充后若内容超过一页，优先精简文字，不允许调小字号或改页边距。
- 路径始终用相对路径 `assets/...`，不写绝对路径或外链。
