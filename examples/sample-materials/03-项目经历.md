# 项目经历

## 项目一：智选电商微服务平台（课程综合项目，个人主导后端）

- 时间：2026.03 - 至今
- 项目类型：微服务架构电商系统，含智能客服
- 技术栈：Java、Spring Boot、Spring Cloud Alibaba（Nacos + Gateway + OpenFeign）、MyBatis-Plus、MySQL、Redis、RabbitMQ、Spring AI、Docker、Maven

### 我做的事

- 按业务把系统拆成用户、商品、订单、购物车、网关 5 个服务，用 Nacos 做注册与配置，Gateway 统一入口路由，OpenFeign 完成服务间调用
- 独立负责订单与购物车模块，编写 20 多个 REST 接口，覆盖下单、库存扣减、订单状态流转等核心场景
- 用 Redis 分布式锁解决高并发下的库存超卖问题，并用 Redis 缓存商品详情，接口平均响应时间从约 200ms 降到 80ms 左右
- 引入 RabbitMQ 处理订单异步消息，通过消息确认和本地消息表保证下单链路的可靠性
- 集成 Spring AI 实现智能客服，结合 RAG 把商品资料和常见问题向量化检索，自动回答发货、退换货等咨询
- 用 Docker Compose 编排 MySQL、Redis、Nacos、RabbitMQ 等依赖，本地一条命令拉起整套环境
- 编写 JUnit 单元测试，核心业务方法覆盖率约 70%

### 产出

- 完成可演示的完整系统，通过课程综合答辩
- 属于教学项目，没有真实上线和用户量，这个数据我给不了，别瞎写

## 项目二：企业知识库 RAG 问答系统（3 人小组，我负责检索后端）

- 时间：2025.10 - 2026.01
- 技术栈：Spring Boot、LangChain4j、Spring AI、PostgreSQL + PGVector、Apache POI、Redis

### 我做的事

- 负责完整 RAG 链路：支持上传 PDF/Word/TXT，用 POI 抽取文本后按段落切片，调用 Embedding 模型向量化写入 PGVector
- 设计检索逻辑：用户提问先向量化，做相似度检索取 Top 5，再用重排序（Rerank）提升相关性，最后拼进提示词交给大模型生成答案并附引用来源
- 对比了 Spring AI 与 LangChain4j 两种接入方式，检索与重排序用 LangChain4j，问答编排用 Spring AI
- 用 Redis 缓存高频问题的检索结果，减少重复调用
- 自建 100 条问答测试集，问答准确率约 85%，平均响应在 2 秒以内

### 产出

- 项目结课获评优秀，接口文档和技术文档由我撰写
- 小组另外两人负责前端与测试，我负责对接联调
