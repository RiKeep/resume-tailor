# 测试用岗位 JD（Java 后端开发实习）

## 职位描述

1. 参与后端服务开发与维护，完成模块级代码编写；
2. 在导师指导下完成需求分析、接口设计与文档撰写；
3. 配合前端、测试、产品等角色，保障功能按时交付；
4. 参与代码评审，编写单元测试，保证代码质量。

## 任职要求

1. 本科及以上在读，计算机相关专业优先；
2. 有扎实的 Java 基础，了解 JVM、多线程、集合等基本原理；
3. 熟悉 Spring Boot、Spring Cloud 等主流框架；
4. 熟悉 MySQL 基本使用，会用 MyBatis-Plus；
5. 了解 Linux 常用命令，会使用 Git、Maven、Docker；
6. 了解常用设计模式，有良好的编码习惯；
7. 有前端经验和 AI 编程工具使用经验，如熟悉 Cursor、Trae 等 AI 编程 IDE，或有 Spring AI、LangChain4j 等大模型应用开发经验者优先；
8. 责任心强，善于沟通，能保证每周至少 4 天、实习 3 个月以上。
