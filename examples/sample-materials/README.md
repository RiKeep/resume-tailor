## 这套素材的测试点

- 大部分 JD 要求能在素材中找到对应事实（匹配项）。
- 含有少量与岗位无关的内容（如部分校园活动、Python 脚本），用于测试内容取舍。
- 个别信息不完整或未量化（如项目用户量、部分数据缺失），用于测试 AI 是否主动确认而非编造。
- 无正式企业实习经历，用于测试技能如何用项目与校园经历合理替代。
